# CICIDS2017 · Adversarial Intrusion Detection

**Role:** Independent project engineering  
**Stack:** Python · PyTorch · CNN · DQN · Robustness Evaluation

[Portfolio](../README.en.md) · [中文版](cicids2017.md) · [Public source code](https://github.com/ck458/CICIDS2017)

## Project objective

Build a network intrusion detector and evaluate its robustness against adversarial network traffic generated by a reinforcement-learning agent.

## Implementation

**Detection model.** Implemented CICIDS2017 data loading and preprocessing, feature conversion, a CNN classifier and training/evaluation routines.

**Adversarial agent.** Built a Deep Q-Network interacting with a detection environment to propose changes to traffic samples and search for adversarial inputs.

**Robustness evaluation.** Integrated detection training, adversarial sample generation, robustness-focused training and multi-metric performance reporting.

**Project architecture.** Kept preprocessing, models, reinforcement learning, attack generation and evaluation in separate Python modules with a unified entry point.

The [public source repository](https://github.com/ck458/CICIDS2017) contains the modular training and evaluation pipeline.
